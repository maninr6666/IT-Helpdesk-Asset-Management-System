# Sample Helpdesk Workflow

## Scenario
User cannot connect to office Wi-Fi.

1. Create ticket.
2. Category: Network.
3. Priority: High.
4. Status: Open.
5. Troubleshoot:
   - Check Wi-Fi adapter.
   - Verify IP configuration.
   - Test gateway connectivity.
   - Reconnect to approved SSID.
6. Add resolution notes.
7. Change status to Resolved.
8. Confirm with user.
9. Change status to Closed.

## RCA Example
Root cause: Incorrect network profile configuration.

Resolution: Removed the stale profile and reconnected using the approved configuration.
